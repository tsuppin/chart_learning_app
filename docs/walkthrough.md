# 相場師朗流・チャートめくり練習アプリ - 利用ガイド

このアプリは、チャート画像をアップロードし、実際の相場のように右側を隠して少しずつめくることで、建玉の練習を行うためのツールです。
最新版では、損益シミュレーション機能とズーム機能が追加されました。

## 使い方

1. **チャート画像のアップロード**
   - 画面上部の「ファイルを選択」ボタン、またはエリアをクリックして、練習したいチャート画像（jpg, png等）をアップロードします。
   - 画像が読み込まれると、右側90%が隠された状態で表示されます。

2. **基本操作**
   - **ズーム機能**: 右パネルの「ズーム」欄にある `+` `-` ボタンで、画像の表示倍率を調整できます（20%〜500%）。
   - **送り幅調整**: 「送り幅(px)」欄の `+` `-` ボタンまたは直接入力で、1回に進む幅（ローソク足の本数に相当）を微調整できます。
   - **現在株価**: その時点の株価を入力すると、損益が計算されます。
   - **建玉入力**: 「売り」「買い」の入力ボックスに、その時点での建玉数（例：2-0）を入力します。
   - **技タグ**: その局面で判断した技（下半身、逆下半身など）を選択します。
   - **次の日へ**: ボタンを押すと、設定した幅だけチャートが右にスライドします。

3. **損益計算機能**
   - 「現在株価」を入力してステップを進めると、以下の損益が自動計算されます。
     - **含み損益**: 現在保有している建玉の評価損益。
     - **確定損益**: 手仕舞い（決済）した分の損益累計。
   - 建玉の平均取得単価（建値）は、加重平均法で自動計算されます。

4. **練習の終了と振り返り**
   - チャートの右端まで到達すると、自動的に終了となり結果が表示されます。
   - **結果表示**:
     - チャート上に、各ステップでの建玉が大玉（吹き出し）で表示されます。
     - **整合性チェック**: タグ付けした技（例：下半身＝売り局面）と、実際の建玉操作（売りが増えているか）が矛盾している場合、赤いボックスで警告が表示されることがあります。

## 機能一覧

- **ダークモードUI**: 長時間の練習でも疲れにくいプロ仕様の配色。
- **ヒストリー表示**: 右サイドバーに、過去のステップごとの建玉履歴がリスト表示されます。
- **整合性評価**: 相場師朗流の基本的なセオリー（下半身は売り、逆下半身は買い）に基づき、入力内容を簡易診断します。
- **PLシミュレーション**: 実践に近い損益管理が可能です。

## 注意事項

- 画像の縮尺によっては「送り幅」の微調整が必要です。
- 評価機能は簡易的なものです。全ての相場状況を自動判定するわけではありません。
